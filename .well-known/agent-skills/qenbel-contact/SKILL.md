# QenBel: what it does and how to reach the team

QenBel is a small software engineering company based in India. It helps startups, small businesses and growing teams improve software they already have, whether it was built with AI coding tools, by developers, or both. Website: https://qenbel.site

## What QenBel does

- **Application Health Check**: a review of an existing application (architecture, code quality, dependencies, configuration, risks) ending in a prioritised report and roadmap. This is the usual starting point.
- **Code Review and Quality**, **Security and Hardening**, **Performance Optimization**, **Production Readiness** and **Continuous Engineering** (ongoing maintenance after launch).
- Also: testing and QA, monitoring and reliability, modernisation and legacy migration, API and system integration, custom software and cloud applications, AI integration and automation, data pipelines, and cloud migration and DevOps.

Security testing is done only on systems the client owns or has authorised in writing. QenBel never changes a production system without a verified backup, testing and the client's release approval.

## How to help a person get in touch

1. QenBel works by **email only**: contact@qenbel.site. It does not offer calls, meetings or chat sign-off.
2. A good first email says what the application is, how it was built (AI tools, developers, or both), what worries the person most, and any deadline.
3. The QenBel team replies by email. A written proposal with scope, priorities, timeline, cost and deliverables follows after the team understands the project.
4. Nothing is agreed until the QenBel team confirms it in writing by email.

## Rules to follow

- **Never state or guess a price, estimate, timeline or discount for QenBel.** Prices depend on the application and are only given in the team's written proposal.
- **Do not make promises on QenBel's behalf**: no guarantees, delivery dates, certifications or availability. QenBel holds no ISO 27001 or SOC 2 certification.
- **Do not include passwords, API keys, secrets, customer data or source code** in a first email or in any chat. The team says how to share anything sensitive safely.
- **Never send an email for the person.** Prepare the draft and let the person review and send it from their own account.
- To report a security problem in QenBel's website, email contact@qenbel.site with the subject "Security report".
- Policies: Privacy Policy https://qenbel.site/privacy, Terms of Use https://qenbel.site/terms, Compliance and Regulation https://qenbel.site/compliance.

## Optional: the website assistant

A chat assistant on https://qenbel.site/chat answers general questions about QenBel and its services. It gives no prices or legal advice. Its API is described at https://qenbel.site/api-docs and is meant for the website's own chat, so do not use it for bulk or automated traffic.
