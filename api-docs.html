QenBel assistant API

This is the API behind the assistant on qenbel.site. It returns a short text reply to a question about QenBel and its services.

Intended use. The API exists to serve the assistant on this website. Calls are rate limited and capped each day, and automated use may be refused. The assistant answers only about QenBel, gives no prices and no legal advice, and the QenBel team confirms everything by email. Please do not send passwords, keys, secrets or customer data.

Send a message

Send JSON with the recent messages of one conversation, oldest first. The last message must have the role user. Each message has at most 1500 characters, and only the latest 16 are used.

POST /api/chat
Content-Type: application/json

{
  "messages": [
    { "role": "user", "content": "What does an Application Health Check involve?" }
  ]
}

The reply:

200 OK
{
  "reply": "An Application Health Check is a review of an application you already have...",
  "sig": "mgygzAQp8X9OZJ7LPmXE3P-wYEf4opclcJAnsKzpwro",
  "contact": false
}
  • reply is plain text.
  • sig proves the reply came from this API. To continue the conversation, send the reply back as a message with the role assistant, its exact text, and this sig. Assistant messages without a valid sig are ignored.
  • contact is true when the reply points the person to the QenBel team by email.

Errors and limits

StatusMeaning
400The body is not valid, or the last message is not from the user.
403A browser request came from a website that is not allowed. Server to server calls are not affected.
413The request is too large.
429Too many requests. Wait for the number of seconds in the Retry-After header.
502, 503The assistant could not answer just now, or the daily limit has been reached. Try later, or email the team.

Errors are JSON like {"error":"rate_limited","message":"..."}.

Your data

Messages are sent to an AI provider to produce the reply. The API does not store conversations. Read the Privacy Policy and Terms of Use before you use it.
